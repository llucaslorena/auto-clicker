# auto-clicker

A Proof of Concept for Android touch automation, designed to generate and execute programmable screen-click scripts.

### Overview
* **Technical Focus:** Shizuku API, ADB Kernel Events (`sendevent`), Android System APIs, Git.
* **Core Architecture:** Developed an early-stage proof-of-concept for low-latency touchscreen automation using system-level event dispatching to automate repetitive tasks on Android.
* **Methodology:** Employed an AI-assisted engineering approach to evaluate the efficacy, speed, and technical limitations of AI code generation in low-level mobile development.
* **Roadmap:** Building a modular touch-automation engine designed to execute complex, multi-point touchscreen scripts and custom macros.
